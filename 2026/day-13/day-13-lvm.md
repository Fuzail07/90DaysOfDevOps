Commands used:

sudo su -- to become root
lvm -- to use logical volume manager
pvs -- to view physical volume
pvcreate -- to create physical volume
lvs -- to view logical volume
lvcreate -- to create logical volume
mkfs -- to format filesystem
vgcreate -- create a volume group 
mkdir -- to create a directory for the disk mount
mount -- to mount the disk
df -- to check the disk free 
lvextend -- to extend the existing logical volume.
